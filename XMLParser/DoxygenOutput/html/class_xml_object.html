Detailed Description

Абстрактен базов клас за всички обекти в XML дървото.

Класът дефинира общ интерфейс за сериализация, клониране и извличане на текстово съдържание. Всички конкретни XML обекти (елементи, текстови възли и коментари) наследяват този клас.
